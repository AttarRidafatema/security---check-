# 🔐 Password Strength Analyzer

A web-based **Password Strength Analyzer** that checks the strength of a password and provides a score, character analysis, and suggestions to help users create stronger and more secure passwords.

## ✨ Features

* 🔒 **Password Strength Analysis** – Analyzes the entered password and evaluates its strength.
* 📊 **Strength Score** – Displays a password strength score out of 100.
* 💪 **Strength Level** – Shows the password strength, such as Weak, Medium, or Strong.
* 📈 **Visual Strength Indicator** – Displays the password strength using a visual indicator.
* 🔍 **Character Analysis** – Analyzes the characters used in the password.
* 🔠 **Uppercase and Lowercase Detection** – Checks whether uppercase and lowercase letters are present.
* 🔢 **Number Detection** – Checks whether the password contains numbers.
* 🔣 **Special Character Detection** – Checks whether special characters are included.
* 📏 **Password Length Check** – Displays the total number of characters in the password.
* 💡 **Personalized Suggestions** – Provides suggestions to improve password strength, such as adding uppercase letters, lowercase letters, numbers, special characters, or using a good password length.
* 👁️ **Password Masking** – Hides the entered password using black dots on the screen.
* 📋 **Password Check History** – Displays the history of previous password strength checks.
* 🎨 **User-Friendly Interface** – Includes a clean, modern, dark-themed design.

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure of the web application.
* **CSS3** – Used to design the interface, layout, colors, and visual effects.
* **JavaScript** – Used to analyze passwords, calculate strength scores, display feedback, and manage the check history.

## 🎯 Project Objective

The main objective of this project is to help users understand the strength of their passwords and learn how to create stronger passwords.

This project aims to:

* Analyze password strength using different character types and password length.
* Display a strength score and strength level.
* Identify missing password requirements.
* Provide useful suggestions to improve password security.
* Create a simple and user-friendly password analysis tool.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Locate the `Pass.html` file.
4. Open the file in any modern web browser.
5. Enter a sample password in the input field.
6. Click the **Analyze** button to check its strength.
7. View the strength score, character analysis, suggestions, and check history.

## 🔒 Disclaimer

This project is created for **educational purposes** to demonstrate basic password strength analysis.

The strength score is an estimate and does not guarantee that a password is secure. Password masking only hides the password visually; it does not guarantee secure storage. Avoid entering real account passwords into this project, especially if password history is stored.
